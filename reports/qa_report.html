4. Assumptions and limits

  • Duplicates: the first copy to arrive is kept; the others are flagged.
  • Speed is measured against the last accepted ping. If the very first ping of a driver were bad, every later ping could be rejected; this dataset keeps the first two pings clean, so that case is not exercised.
  • Off-road = distance to the nearest road of the whole network, not only the driver's own route.
  • Expected km joins genuine pings with straight lines, so it is below true road distance at corners (accepted definition).
  • The answer key exists only for synthetic data; on real data only the billing comparison against a trusted reference could run.
